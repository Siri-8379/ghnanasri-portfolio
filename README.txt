Preview locally:
1. Extract the ZIP file.
2. Open index.html in a browser.

Publish for free (GitHub Pages):
1. Sign in to GitHub and create a new public repository, e.g. ghnanasri-portfolio.
2. Upload index.html (and this README if desired) to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select the main branch and / (root), then Save.
5. GitHub will show your published website URL after deployment finishes.
